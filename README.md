## ⚡ Quick start: your first audit in one afternoon

Short on time? This cut-down version gives you a useful snapshot in about 3 hours.

1. **Pick 10 prompts** from `02-prompt-library.md`: 4 consideration, 3 comparison, 2 decision, 1 accuracy. Replace the placeholders.
2. **Test on 3 platforms:** ChatGPT, Perplexity and Copilot. New chat for every prompt, web search on, logged out where possible.
3. **Log results** in `citation-tracker.csv`: mentioned? position? accurate? which URLs cited? which competitors?
4. **Calculate** your mention rate (mentions ÷ 30 answers) and list the 5 most-cited domains.
5. **Check 3 technical basics:** robots.txt allows AI search crawlers, the site is verified in Bing Webmaster Tools, and key pages are indexed in Google and Bing.
6. **Write down 3 fixes:** usually one technical, one accuracy, one new page (often a comparison or "best X for Y" guide).

## 💡 Key ideas in 2 minutes

- **AI assistants write one answer instead of showing ten links.** If you're not in that answer, you may not make the shortlist.
- **Most AI tools search the web before answering** (called RAG). Good SEO foundations still matter, and **Bing matters as much as Google** for ChatGPT and Copilot.
- **AI quotes passages, not pages.** Answer the question in the first 2–3 sentences of a section.
- **The formats that get cited most:** comparisons ("X vs Y"), "Is X good for Y?", buyer guides ("Best X for Y"), original research, clear FAQs.
- **Mentions ≠ citations.** Track both.
- **Answers vary.** Test regularly with the same prompts and report trends, not single snapshots.
