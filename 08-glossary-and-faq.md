# 08 · Glossary and FAQ

---

## Glossary

| Term | Meaning |
|---|---|
| **AEO (Answer Engine Optimization)** | Optimising content to be the direct answer to questions in answer engines, featured snippets, voice assistants and AI tools. |
| **AI Mode** | Google's conversational AI search experience. |
| **AI Overviews** | AI-written summaries shown at the top of some Google search results, with links to sources. |
| **AI referral traffic** | Website visits that come from clicking links in AI tools (e.g. from chatgpt.com). |
| **Answer-first / BLUF** | Writing style that gives the answer in the first sentences (Bottom Line Up Front). |
| **Bing Webmaster Tools** | Microsoft's free tool for site owners. Includes the AI Performance report for Copilot citations. |
| **Channel group (GA4)** | A set of rules that groups traffic sources (e.g. Organic Search, Referral, AI Search). |
| **Citation** | A link to a source page shown in an AI answer. |
| **Citation share** | Your domain's citations ÷ all citations for a query, as a percentage. |
| **CDN (Content Delivery Network)** | A service that speeds up and protects websites. Its bot settings can block AI crawlers. |
| **Crawler / bot / spider** | A program that visits and reads web pages. |
| **E-E-A-T** | Experience, Expertise, Authoritativeness, Trustworthiness: Google's framework for content quality. Also useful for AI visibility. |
| **Entity** | A distinct "thing" search engines and AI recognise: a brand, person, product or place. |
| **Featured snippet** | A highlighted answer box at the top of Google results. |
| **Funnel stage** | Where the buyer is: awareness, consideration, comparison, decision. |
| **GA4** | Google Analytics 4, Google's website analytics tool. |
| **GEO (Generative Engine Optimization)** | Optimising to be mentioned and cited in answers created by generative AI. |
| **Grounding** | When an AI bases its answer on retrieved sources (rather than memory alone). |
| **Hallucination** | When AI states something false with confidence. |
| **Indexing** | When a search engine stores a page so it can appear in results. |
| **IndexNow** | A protocol that notifies Bing and other engines immediately when pages change. |
| **JSON-LD** | The recommended format for adding structured data (schema) to pages. |
| **LLM (Large Language Model)** | The AI model behind tools like ChatGPT, Claude and Gemini. |
| **llms.txt** | A proposed file that summarises a site for AI tools. Not confirmed as used by major platforms. |
| **Mention** | Your brand's name appearing in an AI answer. |
| **Mention rate** | Answers that mention your brand ÷ total answers tested, as a percentage. |
| **Passage** | A section of a page (a paragraph or block) that AI can quote on its own. |
| **Prompt** | The question or instruction typed into an AI tool. |
| **Query fan-out** | When AI turns one question into several related searches behind the scenes. |
| **RAG (Retrieval-Augmented Generation)** | The process of fetching sources and using them to write an answer. |
| **robots.txt** | A file that tells crawlers which parts of a site they can visit. |
| **Schema / structured data** | Code that labels page content (Organization, FAQ, Product…) for machines. |
| **Search Console** | Google's free tool for site owners to see search performance and indexing. |
| **Share of voice** | A brand's mentions ÷ all brand mentions in a set of answers, as a percentage. |
| **SEO (Search Engine Optimization)** | Improving pages so they rank higher in search results. |
| **Sitemap** | A file listing a site's pages to help search engines find them. |
| **Training data** | Text an AI model learned from before release. |
| **User agent** | The name a crawler uses to identify itself (e.g. `OAI-SearchBot`). |
| **Zero-click search** | When the user gets the answer without clicking any link. |

## FAQ

### Is GEO different from SEO?
GEO builds on SEO. SEO helps your pages get found and ranked; GEO focuses on being quoted and recommended inside AI answers. Most good GEO work starts with SEO foundations: crawlable, indexed, well-structured pages.

### How long does it take to see results?
Technical fixes and updates to existing pages can show up in AI answers that use live search within weeks. New content usually takes 1–3 months to be indexed, trusted and cited. Changing what a model "remembers" from training data takes much longer.

### Can I pay to appear in ChatGPT or Perplexity answers?
Organic AI answers aren't sold like search ads. Some platforms are introducing ads, but those are labelled separately. Organic visibility comes from content and reputation.

### Why do I get different answers each time I ask?
AI tools generate answers fresh each time, and results vary with wording, location, personalisation and which sources were retrieved. That's why you repeat key prompts and track trends.

### Which platform should I focus on?
Where your buyers are. For B2B in Microsoft-heavy industries (like law), **Copilot** matters a lot. **ChatGPT** has the largest general audience. **Google AI Overviews** reach everyone who uses Google. Start by making sure you're indexed in both **Google and Bing**, which covers most platforms.

### Should I block AI training crawlers?
It's a business decision. Blocking training crawlers (like GPTBot) protects content from being used for training but doesn't affect AI search visibility, as long as you allow the search crawlers (like OAI-SearchBot). See `05-technical-setup.md`.

### Do I need llms.txt?
It's optional and low priority. Major platforms haven't confirmed using it. Focus on crawlability, content and reputation first.

### Does schema markup guarantee citations?
No. Schema helps machines understand your pages, but content quality, relevance and authority decide whether you're cited.

### What if AI says something wrong about my brand?
1. Find the likely source (check the citations on that answer).
2. Fix it at the source: update your own pages, and ask third-party sites to correct outdated information.
3. Publish clear, current facts on your site (about page, pricing, features, FAQ).
4. Re-test in a few weeks. Some platforms also have feedback buttons on answers.

### How many prompts should I test?
20–30 per brand is a good balance between coverage and time. Include all funnel stages, weighted toward consideration and comparison.

### Can small businesses compete with big brands?
Yes. For specific, niche questions ("best POS for kiosk ordering in Brisbane"), a focused page with specific facts often beats a big brand's generic page.

### How do I prove ROI?
Combine layers: mention rate trend (presence), Bing citations (citation), GA4 AI referral sessions and engagement (traffic), and leads or demos from AI referrals (business). Track monthly against a baseline.
